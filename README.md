#### Installation
##### English:
- Open the Extensions sidebar in VS Code:
  - Navigate to View → Extensions.
  - Search for **"Cyberpunk 2021"** or [view it directly on the Marketplace](https://marketplace.visualstudio.com/items?itemName=techwithcarlos.cyberpunk-2021).
  - Click **Install**.
- Select the theme:
  - Go to Code → Settings → Theme → Color Theme and select "Cyberpunk 2021".
  - Or use the Command Palette (Cmd + Shift + P / Ctrl + Shift + P) and select Preferences: Color Theme.
- Optional: Apply the recommended settings below for the best experience.
- **Usage:** Select Cyberpunk 2021 and enjoy coding!
- **Shortcut:**
  - macOS: Cmd + K, Cmd + T
  - Windows/Linux: Ctrl + K, Ctrl + T

##### Deutsch:
- Öffne die Erweiterungen-Seitenleiste in VS Code:
  - Gehe zu Ansicht → Erweiterungen.
  - Suche nach **"Cyberpunk 2021"** oder [ansicht direkt im Marketplace](https://marketplace.visualstudio.com/items?itemName=techwithcarlos.cyberpunk-2021).
  - Klicke auf **„Installieren“**.
- Wähle das Theme aus:
  - Gehe zu Code → Einstellungen → Theme → Farbschema und wähle „Cyberpunk 2021“.
  - Oder öffne die Befehlspalette (Cmd + Shift + P / Ctrl + Shift + P) und wähle „Einstellungen: Farbschema“.
- Optional: Wende die empfohlenen Einstellungen unten für das beste Ergebnis an.
- **Benutzung:** Wähle Cyberpunk 2021 und viel Spaß beim Programmieren!
- **Shortcut:**
  - macOS: Cmd + K, Cmd + T
  - Windows/Linux: Ctrl + K, Ctrl + T

#### Recommended Settings:

**English:** Optimized for intense and focused programming.

**Deutsch:** Optimiert für intensives und fokussiertes Programmieren.

```jsonc
{
  "workbench.colorTheme": "Cyberpunk 2021",

  // Recommended editor font 
  // Empfohlene Editor-Schriftart 
  "editor.fontFamily": "JetBrains Mono", 
  "editor.fontSize": 16, 
  "editor.lineHeight": 1.5,

  // Recommended terminal font with Powerline and icon support 
  // Empfohlene Terminal-Schriftart mit Powerline- und Icon-Unterstützung
  "terminal.integrated.fontFamily": "'Hack Nerd Font', monospace",

  // Trim trailing whitespace on save 
  // Entfernt Leerzeichen am Zeilenende beim Speichern 
  "files.trimTrailingWhitespace": true,

  // Do not render whitespace characters
  // Keine Leerzeichen anzeigen
  "editor.renderWhitespace": "none",

  // Keep individual code characters clearly distinguishable 
  // Klare Darstellung einzelner Zeichen ohne Ligaturen
  "editor.fontLigatures": false
}
```
